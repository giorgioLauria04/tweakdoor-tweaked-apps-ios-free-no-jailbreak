### 📋 Installation Guide

1. Open the Tweakdoor web repository on your iOS device using Safari.
2. Browse the available tweaked application catalog and select the app you want to install.
3. Tap the install button. Safari will prompt you to confirm the installation of a configuration profile or a signed application package.
4. **Important Notice:** iOS will display an "Untrusted Developer" warning the first time you launch the app. This is expected behavior for enterprise-signed applications distributed outside the App Store.
5. Navigate to Settings → General → VPN & Device Management.
6. Locate the developer profile associated with the signing certificate and tap "Trust".
7. Return to the home screen and launch the installed application.

### ❓ Troubleshooting & Support

- **Issue:** *The application crashes immediately after launch.*
  **Solution:** The signing certificate has likely been revoked. Remove the app and reinstall it from the repository using a different signing method.
- **Issue:** *Error: "Unable to Install – This app cannot be installed because its integrity could not be verified."*
  **Solution:** The certificate has been revoked by Apple. Wait for the repository to issue a new certificate or use an alternative signing service.
- **Issue:** *The app stops working after a few days.*
  **Solution:** Enterprise certificates are periodically revoked. Reinstall the application or use a developer certificate with a longer validity period.
- **Issue:** *Cannot find the profile in VPN & Device Management.*
  **Solution:** Ensure the installation completed fully. If the profile does not appear, delete the app and reinstall it.

### ⚠️ Important Considerations

- Tweaked applications are distributed outside the official App Store and are not reviewed by Apple.
- Enterprise certificates used for distribution can be revoked at any time, causing installed apps to stop working.
- Some tweaked apps may violate the terms of service of the original application.
- Always download from a source you trust, and avoid entering sensitive personal or payment information into modified applications.
- Keep a backup of your device data before installing third-party signed applications.
